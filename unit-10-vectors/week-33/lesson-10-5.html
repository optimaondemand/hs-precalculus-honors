Magnitude and Direction of Scalar Multiples; Unit Vectors
Lesson
🎯 LEARNING OBJECTIVES

  • I will be able to compute the magnitude and direction angle of a scalar multiple \(k\mathbf{v}\), and state the rule \(|k\mathbf{v}|=|k|\,|\mathbf{v}|\) without a calculator's help.

  • I will be able to normalize any nonzero vector into a unit vector \(\hat{u}=\mathbf{v}/|\mathbf{v}|\), and verify by computation that \(|\hat{u}|=1\).

  • I will be able to build a vector of any desired magnitude pointing in a given direction, by scaling a unit vector.

  • I will be able to explain, using the distance formula, why multiplying a vector by a negative scalar reverses its direction by exactly \(180^\circ\) while multiplying by a positive scalar leaves the direction unchanged.

📚 VOCABULARY

Scalar multiple: the vector \(k\mathbf{v}\) formed by multiplying every component of \(\mathbf{v}\) by the real number \(k\); if \(\mathbf{v}=(a,b)\), then \(k\mathbf{v}=(ka,kb)\).

Unit vector: a vector whose magnitude is exactly \(1\). Any nonzero vector has exactly one unit vector pointing in its own direction and one pointing in the opposite direction.

Normalizing a vector: dividing a vector by its own magnitude, \(\hat{u}=\dfrac{\mathbf{v}}{|\mathbf{v}|}\), to produce the unit vector that shares its direction.

Direction angle: the angle \(\theta\), measured counterclockwise from the positive \(x\)-axis, that a vector makes — the same direction angle you have been computing since Lesson 10-1.

💡 EXPLORING THE MATH

You already know how to scale a vector: multiply every component by the same number \(k\), and the vector \(\mathbf{v}=(a,b)\) becomes \(k\mathbf{v}=(ka,kb)\). Lesson 10-4 asked you to picture what that does — stretches the arrow, shrinks it, or flips it around to point the opposite way. Today you make that picture precise. Given \(\mathbf{v}=(a,b)\) with magnitude \(|\mathbf{v}|=\sqrt{a^2+b^2}\), the scalar multiple \(k\mathbf{v}=(ka,kb)\) has magnitude

\(|k\mathbf{v}| = \sqrt{(ka)^2+(kb)^2} = \sqrt{k^2(a^2+b^2)} = |k|\sqrt{a^2+b^2} = |k|\,|\mathbf{v}|\)

Notice the absolute value bars survive on \(k\) even when \(k\) itself is negative — a magnitude is a length, and lengths are never negative. The direction tells the rest of the story: multiplying by a positive \(k\) leaves the direction angle exactly where it was, while multiplying by a negative \(k\) sends the vector to the exact opposite ray, which is the same thing as adding \(180^\circ\) to the direction angle.

Scalar Multiples: Magnitude and Direction

\(|k\mathbf{v}| = |k|\,|\mathbf{v}|\)

If \(k>0\): the direction angle of \(k\mathbf{v}\) equals the direction angle of \(\mathbf{v}\) — same ray, new length.

If \(k<0\): the direction angle of \(k\mathbf{v}\) equals the direction angle of \(\mathbf{v}\), plus \(180^\circ\) — the opposite ray, and (unless \(|k|=1\)) a new length as well.

Example 1

Let \(\mathbf{v}=(-6,8)\). Compute \(|\mathbf{v}|\) and its direction angle. Then compute \(3\mathbf{v}\) and \(-3\mathbf{v}\), and state each one's magnitude and direction.

Solution:

\(|\mathbf{v}|=\sqrt{(-6)^2+8^2}=\sqrt{36+64}=\sqrt{100}=10\). Since \(x<0\) and \(y>0\), \(\mathbf{v}\) sits in Quadrant II. Reference angle: \(\tan^{-1}\!\left(\dfrac{8}{6}\right)\approx53.13^\circ\), so \(\theta=180^\circ-53.13^\circ\approx126.87^\circ\).

\(3\mathbf{v}=(-18,24)\). Check: \(|3\mathbf{v}|=\sqrt{18^2+24^2}=\sqrt{324+576}=\sqrt{900}=30=3(10)\). ✓ Same quadrant as \(\mathbf{v}\), so the direction angle is the same, \(126.87^\circ\).

\(-3\mathbf{v}=(18,-24)\). Check: \(|{-3}\mathbf{v}|=\sqrt{18^2+24^2}=30=|{-3}|(10)\). ✓ This point is in Quadrant IV (opposite quadrant from \(\mathbf{v}\)), and \(126.87^\circ+180^\circ=306.87^\circ\) — exactly where \((18,-24)\) plots.

Answer: \(|\mathbf{v}|=10\), \(\theta\approx126.87^\circ\); \(3\mathbf{v}=(-18,24)\) has magnitude \(30\) and the same direction; \(-3\mathbf{v}=(18,-24)\) has magnitude \(30\) and direction \(306.87^\circ\), exactly \(180^\circ\) opposite.

The Unit Vector: A Direction, Stripped of Length

Every nonzero vector \(\mathbf{v}\) points in some direction and has some length. A unit vector separates those two facts: dividing \(\mathbf{v}\) by its own magnitude,

\(\hat{u} = \dfrac{\mathbf{v}}{|\mathbf{v}|} = \left(\dfrac{a}{|\mathbf{v}|},\ \dfrac{b}{|\mathbf{v}|}\right)\)

produces a vector with magnitude exactly \(1\) that keeps \(\mathbf{v}\)'s exact direction. This is dividing, which is scalar multiplication by \(k=\dfrac{1}{|\mathbf{v}|}\) — a positive number — so by the rule above, the direction never changes; only the length is rescaled to \(1\).

Example 2

Normalize \(\mathbf{v}=(-5,12)\).

Solution:

\(|\mathbf{v}|=\sqrt{(-5)^2+12^2}=\sqrt{25+144}=\sqrt{169}=13\).

\(\hat{u} = \left(\dfrac{-5}{13},\ \dfrac{12}{13}\right)\)

Verify: \(|\hat{u}|=\sqrt{\left(\dfrac{-5}{13}\right)^2+\left(\dfrac{12}{13}\right)^2}=\sqrt{\dfrac{25}{169}+\dfrac{144}{169}}=\sqrt{\dfrac{169}{169}}=\sqrt{1}=1\). ✓

Answer: \(\hat{u}=\left(-\dfrac{5}{13},\dfrac{12}{13}\right)\), a unit vector pointing in exactly the same direction as \(\mathbf{v}\).

Key Fact: Building a Vector of Any Length You Want

Once you have a unit vector \(\hat{u}\) for a direction, you can build a vector of any magnitude \(m\) pointing that same way, simply by scaling: \(m\hat{u}\). Since \(|\hat{u}|=1\), the rule \(|k\mathbf{v}|=|k|\,|\mathbf{v}|\) guarantees \(|m\hat{u}|=|m|\cdot1=|m|\) — the unit vector is a direction, purified of length, waiting for you to hand it whatever length the problem calls for. This is exactly how a pilot's heading (a direction) and airspeed (a length) get combined into a single velocity vector in Lesson 10-9.

Example 3

Build a vector of magnitude \(20\) that points in the same direction as \(\mathbf{w}=(4,-3)\).

Solution:

\(|\mathbf{w}|=\sqrt{4^2+(-3)^2}=\sqrt{16+9}=\sqrt{25}=5\). Unit vector: \(\hat{u}=\left(\dfrac{4}{5},-\dfrac{3}{5}\right)\).

\(20\hat{u} = \left(20\cdot\dfrac{4}{5},\ 20\cdot\left(-\dfrac{3}{5}\right)\right) = (16,-12)\)

Check: \(|(16,-12)|=\sqrt{16^2+12^2}=\sqrt{256+144}=\sqrt{400}=20\). ✓

Answer: \((16,-12)\) — magnitude \(20\), same direction as \(\mathbf{w}\).

Example 4

Build a vector of magnitude \(8\) whose direction angle is \(120^\circ\).

Solution:

The unit vector for a direction angle \(\theta\) is always \(\hat{u}=(\cos\theta,\sin\theta)\), since \((\cos\theta)^2+(\sin\theta)^2=1\) guarantees magnitude \(1\) by the Pythagorean identity. Here, \(\hat{u}=(\cos120^\circ,\sin120^\circ)=\left(-\dfrac12,\dfrac{\sqrt3}{2}\right)\).

\(8\hat{u} = \left(8\cdot\left(-\dfrac12\right),\ 8\cdot\dfrac{\sqrt3}{2}\right) = (-4,\ 4\sqrt3)\)

Check: \(|(-4,4\sqrt3)|=\sqrt{(-4)^2+(4\sqrt3)^2}=\sqrt{16+48}=\sqrt{64}=8\). ✓

Answer: \((-4,4\sqrt3)\approx(-4,6.93)\).

💻 On Your Calculator: Watching a Scalar Multiple Stretch and Flip

At desmos.com/calculator (or below), plot the point (-6, 8) and draw the vector from the origin using a segment or Desmos's vector notation. Then plot (-18, 24) and (18, -24) from Example 1 on the same graph. Watching all three at once makes the rule visible: the two scalar multiples fall on the exact same line through the origin as \(\mathbf{v}\) — \(3\mathbf{v}\) stretched out along it, \(-3\mathbf{v}\) stretched out the other way — because scaling a vector by any real number keeps every resulting arrow on that one line.

▶  Try it yourself: Normalize \(\mathbf{v}=(-8,6)\), then build a vector of magnitude \(25\) in that same direction.
\(|\mathbf{v}|=\sqrt{(-8)^2+6^2}=\sqrt{64+36}=\sqrt{100}=10\), so \(\hat{u}=\left(-\dfrac{8}{10},\dfrac{6}{10}\right)=(-0.8,0.6)\). Check: \((-0.8)^2+(0.6)^2=0.64+0.36=1\). ✓ Scaling to magnitude \(25\): \(25\hat{u}=(-20,15)\). Check: \(\sqrt{(-20)^2+15^2}=\sqrt{400+225}=\sqrt{625}=25\). ✓
⚠️ COMMON MISTAKE
Normalizing only one component instead of dividing both by the magnitude. Given \(\mathbf{v}=(9,12)\) with \(|\mathbf{v}|=15\), a common slip writes \(\hat{u}=\left(\dfrac{9}{15},12\right)\) — dividing the first coordinate but leaving the second untouched. That vector is not a unit vector at all: \(\sqrt{0.6^2+12^2}\approx12.01\), nowhere near \(1\). Every component gets divided by the same magnitude: \(\hat{u}=\left(\dfrac{9}{15},\dfrac{12}{15}\right)=(0.6,0.8)\), which does check out to length \(1\).

Conclusion

A scalar multiple is really two separate stories told in one instruction: the absolute value of \(k\) rescales the length, and the sign of \(k\) decides whether the direction stays put or flips a full \(180^\circ\). Split those two stories apart entirely, and you get the unit vector — pure direction, length \(1\), ready to be handed any magnitude a problem asks for. Tomorrow you give vectors two more addresses to go with the component form you have used since Lesson 10-1: a linear form that names the same numbers with a new notation, and a trigonometric form that writes a vector the way you now write a direction — as a magnitude riding on a cosine and a sine.

❓ ESSENTIAL QUESTIONS

1. Why does the rule \(|k\mathbf{v}|=|k|\,|\mathbf{v}|\) need absolute value bars around \(k\), when magnitude itself is already never negative?

2. In Example 1, why is the direction angle of \(-3\mathbf{v}\) exactly \(180^\circ\) more than the direction angle of \(\mathbf{v}\), rather than, say, \(90^\circ\) or some other amount?

3. Why does dividing a vector by its own magnitude always produce a vector of length exactly \(1\), for any nonzero vector at all — not just the specific ones in today's examples?

4. How does separating a vector's direction (the unit vector) from its length (the scalar) make it easier to build a vector to order, the way Example 3 and Example 4 did?
