📋 ASSIGNMENT OVERVIEW
This set drills the constitution of piecewise functions from Lesson 3-11: evaluations that respect each territory's law, graphs whose open and closed dots record who owns every boundary, definitions written from graphs, and the unmasking of absolute-value and step functions as piecewise in disguise. This is a practice set: scored for honest completion, with worked solutions released after the due date for line-by-line self-correction.
🎯 FOCUS QUESTION
One function, several laws, and a border between every pair. Who owns each boundary point — and what breaks if two laws claim the same ground?
📝 PROBLEM SET

Show your work for every problem in neat vertical form — one step per line, final answers labeled. Draw graphs large, with every open and closed dot drawn deliberately — the dots are the answer.

1
Boundary evaluations: For \(f(x) = \begin{cases} 2x + 7 & \text{if } x < -2 \\ x^2 & \text{if } -2 \leq x < 1 \\ 5 - x & \text{if } x \geq 1 \end{cases}\), evaluate \(f(-4)\), \(f(-2)\), \(f(0)\), \(f(1)\), and \(f(3)\). For each of the two boundary inputs, state in a phrase which piece owns it and how you know.
2
Hand-graph #1: Graph the function \(f\) from problem 1, with correct open and closed dots at both boundaries. State where the graph jumps, if anywhere, and where it is a sewn seam.
3
Hand-graph #2: Graph \(g(x) = \begin{cases} -x - 1 & \text{if } x \leq -1 \\ 2 & \text{if } -1 < x < 2 \\ x + 1 & \text{if } x \geq 2 \end{cases}\) with every endpoint dot correct, and state the function's range from your graph.
4
Write from the graph: A graph shows: for \(x < 0\), the line \(y = x + 3\) ending in an open dot at \((0, 3)\); for \(0 \leq x \leq 2\), the horizontal segment \(y = 1\) with closed dots at \((0, 1)\) and \((2, 1)\); for \(x > 2\), the line \(y = x\) beginning with an open dot at \((2, 2)\). Write the full piecewise definition, making every inequality match its dot.
5
Unmask the absolute values: Rewrite each as a piecewise function, and spot-check each piece with one test value:   ① \(f(x) = |2x - 6|\)   ② \(g(x) = |x + 2|\). State the corner point of each graph.
6
Step function: A bicycle-rental stand charges \$5 for the first half hour or any part of it, and \$3 for each additional half hour or part. Write the piecewise cost function for rentals up to 2 hours, and graph it as a staircase — taking care that each step's endpoints (open on one side, closed on the other) match the phrase “or any part.” What does a rider who returns the bike at exactly 60 minutes pay?
7
Explain why: Suppose two pieces of a definition both claim the boundary \(x = 2\) — one says \(x \leq 2\) with value 3 there, the other says \(x \geq 2\) with value 5 there. In two or three sentences, explain precisely what property fails and why the graph's vertical line test exposes it. Then state the repair.
8
Honors stretch: Rewrite \(f(x) = |x - 1| + |x + 2|\) as a piecewise function with no absolute-value bars. (Two inside quantities change sign at two different places — so the number line breaks into three territories; handle each separately, and verify each piece with a test value.) Graph the result, and describe the surprise in the middle territory in one sentence.
💡 CHECK YOURSELF WITH DESMOS
After solving on paper, verify problems 2, 3, and 8 in Desmos (desmos.com/calculator) using the curly-brace syntax from the lesson — e.g. {x < -2: 2x + 7, -2 <= x < 1: x^2, x >= 1: 5 - x}. The shapes should match your hand graphs exactly — but remember that Desmos draws no open or closed dots, so your paper carries information the screen cannot. The calculator confirms; your algebra convinces.
