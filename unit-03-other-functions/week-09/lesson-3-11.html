Piecewise Functions
Lesson
🎯 LEARNING OBJECTIVES

  • I will be able to evaluate piecewise-defined functions at any input, including the boundary points where the rules change.

  • I will be able to graph piecewise functions with correct open and closed endpoints, and write a piecewise definition from a given graph.

  • I will be able to recognize absolute-value and step functions as piecewise functions in disguise, and rewrite them explicitly.

📚 VOCABULARY

Piecewise-defined function: A single function whose rule is given by different formulas on different parts of its domain — one function, several laws, each ruling its own territory.

Boundary point: An input where the governing formula changes. Exactly one piece must own each boundary in the domain, marked by which inequality carries the equals sign.

Step function: A piecewise function that is constant on each piece, so its graph is a staircase of horizontal segments.

Greatest-integer (floor) function: \(\lfloor x \rfloor\) = the greatest integer less than or equal to \(x\); for example \(\lfloor 3.7 \rfloor = 3\) and \(\lfloor -1.2 \rfloor = -2\). The purest of the step functions.

💡 EXPLORING THE MATH

In 1840, the English reformer Rowland Hill talked Parliament into one of history's great simplifications: the Penny Post. One flat penny would carry a letter anywhere in Britain — provided it weighed no more than half an ounce; heavier letters paid more, by weight class. Without meaning to, the Post Office had published one of public life's first great step functions: cost as a function of weight, constant on each interval, jumping at each threshold. Every parking garage, shipping calculator, and postage chart since has run on the same idea — and behind them all stands today's object of wonder: a single function stitched together from different rules, each sovereign over its own stretch of the number line.

Here is the general form. A piecewise-defined function lists formulas and territories side by side:

\(f(x) = \begin{cases} x + 4 & \text{if } x < -1 \\ 2 & \text{if } -1 \leq x < 2 \\ x^2 - 3 & \text{if } x \geq 2 \end{cases}\)

To evaluate \(f\) anywhere, do exactly one thing first: find which territory the input lives in, then apply that territory's law and no other.

Example 1

For the function \(f\) above, evaluate \(f(-3)\), \(f(-1)\), \(f(0)\), \(f(2)\), and \(f(4)\).

Solution:

\(f(-3)\):   \(-3 < -1\), first law: \(-3 + 4 = 1\)

\(f(-1)\):   a boundary — and the second law owns it, because its inequality \(-1 \leq x\) carries the equals sign: \(f(-1) = 2\)

\(f(0)\):   \(-1 \leq 0 < 2\), second law: \(f(0) = 2\)

\(f(2)\):   the other boundary — owned by the third law (\(x \geq 2\) includes 2): \(2^2 - 3 = 1\)

\(f(4)\):   \(4 \geq 2\), third law: \(4^2 - 3 = 13\)

Answer: \(f(-3) = 1\), \(f(-1) = 2\), \(f(0) = 2\), \(f(2) = 1\), \(f(4) = 13\). The two boundary evaluations are the ones that matter: at each border, the piece whose inequality includes equality owns the point. Read the \(\leq\) and \(<\) symbols like property deeds.

Example 2

Graph \(g(x) = \begin{cases} -x & \text{if } x < 0 \\ 3 & \text{if } 0 \leq x < 2 \\ x - 1 & \text{if } x \geq 2 \end{cases}\) with correct open and closed endpoints.

Solution:

Graph each law on its own territory only:

First piece (\(x < 0\)): the line \(y = -x\), coming down from upper left toward the origin. At the border \(x = 0\) this piece does not own the point — draw an open dot at \((0, 0)\).

Second piece (\(0 \leq x < 2\)): the horizontal segment at height 3. It owns its left border — closed dot at \((0, 3)\) — but not its right: open dot at \((2, 3)\).

Third piece (\(x \geq 2\)): the line \(y = x - 1\), starting with a closed dot at \((2, 1)\) and rising to the right.

Answer: The graph has two jumps — at \(x = 0\) the function leaps from near 0 up to 3, and at \(x = 2\) it drops from near 3 down to 1. At each boundary, exactly one solid dot: run the vertical line test at \(x = 0\) and \(x = 2\) and it passes, because open dots do not count as points of the graph. One owner per border — that is what keeps this a function.

Example 3

Write the absolute-value function \(|x|\) as a piecewise function; then rewrite \(f(x) = |x - 3|\) as a two-piece function.

Solution:

Absolute value is a piecewise function that has been wearing a disguise all these years:

\(|x| = \begin{cases} x & \text{if } x \geq 0 \\ -x & \text{if } x < 0 \end{cases}\)

For \(|x - 3|\), the quantity inside changes sign at \(x = 3\), so that is the boundary. When \(x \geq 3\), the inside \(x - 3\) is already nonnegative and the bars do nothing; when \(x < 3\), the bars flip the sign:

\(|x - 3| = \begin{cases} x - 3 & \text{if } x \geq 3 \\ 3 - x & \text{if } x < 3 \end{cases}\)

Spot-check both territories: \(x = 5\): \(|2| = 2\) and \(5 - 3 = 2\) ✓; \(x = 1\): \(|-2| = 2\) and \(3 - 1 = 2\) ✓.

Answer: As boxed above. The famous V-shaped graph is simply two half-lines of slope \(-1\) and \(+1\) meeting at the corner \((3, 0)\) — no jump this time, because both formulas agree at the boundary. A corner is a seam sewn shut; a jump is a seam left open.

Example 4

A parking garage charges \$4 for the first hour or any part of it, and \$2 more for each additional hour or part. Write and graph the cost function for stays up to 4 hours.

Solution:

“Or any part” is the phrase that builds the staircase: one minute into a new hour costs the same as the whole hour. For a stay of \(t\) hours:

\(C(t) = \begin{cases} 4 & \text{if } 0 < t \leq 1 \\ 6 & \text{if } 1 < t \leq 2 \\ 8 & \text{if } 2 < t \leq 3 \\ 10 & \text{if } 3 < t \leq 4 \end{cases}\)

The endpoint dots carry the policy. Staying exactly one hour costs \$4 — so \((1, 4)\) is a closed dot on the first step, and the second step starts with an open dot at \((1, 6)\): each step is closed on the right, open on the left.

Answer: Four horizontal steps at heights 4, 6, 8, 10, each open at its left end and closed at its right. Notice what a step function's jump means in money: at \(t = 2\) hours exactly you pay \$6, but at \(2\) hours and one minute you pay \$8 — the two-dollar jump happens in an instant. Tomorrow we will meet piecewise models where a jump like that would be an injustice, and the seams must be sewn shut.

💻 In Desmos: Piecewise Syntax — and What the Pixels Can't Say 8 min

Desmos writes piecewise functions with curly braces: each piece is condition: formula, separated by commas. At desmos.com/calculator (or below):

  1. Type Example 2 exactly as: g(x) = {x < 0: -x, 0 <= x < 2: 3, x >= 2: x - 1}. (Type <= for \(\leq\); Desmos converts it.) The three territories appear as one graph.
  2. Click the graph just left and just right of \(x = 2\) and read the coordinates — the jump from near 3 down to 1 is plain in the numbers.
  3. Now look closely at the boundaries: Desmos draws no open or closed dots. The pixels at \(x = 0\) and \(x = 2\) look the same whichever piece owns the border. Your hand graph must say what the machine cannot: the deed to each boundary point. This is the same “pixels versus proof” lesson as Unit 2's invisible holes — the calculator confirms the shape; your open and closed dots certify the ownership.
  4. Bonus: type floor(x) and meet the greatest-integer staircase from the vocabulary card.

▶  Try it yourself: For \(h(x) = \begin{cases} x^2 & \text{if } x \leq 1 \\ 4 - x & \text{if } x > 1 \end{cases}\), evaluate \(h(-2)\), \(h(1)\), and \(h(3)\), and state whether the graph jumps at the boundary. Work it on paper before you peek.
\(h(-2) = (-2)^2 = 4\); \(h(1)\) is owned by the first piece (\(x \leq 1\)): \(h(1) = 1\); \(h(3) = 4 - 3 = 1\). At the boundary the first piece ends at height \(1^2 = 1\) (closed) while the second approaches \(4 - 1 = 3\) (open dot at \((1,3)\)) — the graph jumps from 1 up toward 3 as you cross \(x = 1\).
▶  Try it yourself: A graph shows the line \(y = x + 2\) for \(x < 1\) ending in an open dot at \((1, 3)\), then the horizontal line \(y = 5\) for \(x \geq 1\) starting with a closed dot at \((1, 5)\). Write the piecewise definition.
\(f(x) = \begin{cases} x + 2 & \text{if } x < 1 \\ 5 & \text{if } x \geq 1 \end{cases}\) — the open dot tells you the first piece's inequality is strict, and the closed dot gives the second piece the deed to \(x = 1\).
⚠️ COMMON MISTAKE
Giving a boundary point to both pieces — writing \(x \leq 2\) on one piece and \(x \geq 2\) on the next. If the two formulas give different values there, the “function” now assigns two outputs to one input: the graph carries two solid dots on one vertical line, fails the vertical line test, and is no longer a function at all. One piece owns each boundary; the other yields with a strict inequality. (If the two formulas happen to agree at the seam — as in Example 3's corner — the double claim does no visible harm, but the definition is still sloppy law. Write the deed cleanly every time.)

Conclusion

A piecewise function is one function under several laws, and today you learned its constitution: each territory is governed by its own formula, each boundary is owned by exactly one piece, and the open and closed dots on your hand-drawn graph are the legal record the pixels cannot keep. Absolute value turned out to be piecewise in disguise, and the Penny Post's staircase showed how a step function turns thresholds into jumps. Tomorrow the pieces go to work on real policy — tax brackets, shipping tiers, phone plans — where the breakpoints are where all the arguments happen, and the difference between a seam sewn shut and a seam left open is the difference between a fair rule and a cliff. Bring today's boundary discipline; entire paychecks will depend on it.

❓ ESSENTIAL QUESTIONS

1. What must you determine before applying any formula when evaluating a piecewise function, and where do most evaluation errors actually happen?

2. Why can only one piece own each boundary point, and what breaks — precisely — if two pieces with different values both claim it?

3. In what sense are absolute-value and step functions piecewise functions in disguise, and what distinguishes a corner from a jump at a seam?

4. What information do the open and closed dots on a hand-drawn graph carry that a graphing calculator's rendering cannot?
