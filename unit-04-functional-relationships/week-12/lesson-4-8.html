🎯 LEARNING OBJECTIVES

  • I will be able to state the definition of inverse functions and the notation \(f^{-1}\), and explain why \(f^{-1}\) does not mean \(\frac{1}{f}\).

  • I will be able to verify by composition — in both orders — that two functions are inverses, and reject near-misses that fail the ceremony.

  • I will be able to read inverse values from swapped input-output pairs, and recognize the exponential-logarithm pair from Unit 3 as inverses.

📚 VOCABULARY

Inverse function: The function \(f^{-1}\) that exactly undoes \(f\): whenever \(f\) sends \(a\) to \(b\), \(f^{-1}\) sends \(b\) back to \(a\). From the Latin invertere, “to turn about.”

Identity function: The do-nothing function \(I(x) = x\), which returns every input unchanged. It plays the role for composition that 1 plays for multiplication and 0 for addition.

Invertible: A function that has an inverse. Not every function does — today's honors stretch shows you why, and next week supplies the repair.

Self-inverse: A function that is its own inverse, undoing itself: \(f(f(x)) = x\).

💡 EXPLORING THE MATH

This week began with Leibniz naming the function and Euler dressing it in \(f(x)\); it ends with a third act of notation. In 1813, the English astronomer John Herschel — son of the William Herschel who discovered Uranus — proposed writing \(f^{-1}(x)\) for the function that undoes \(f\). His logic was Wednesday's lesson taken seriously: if \(f^2(x)\) means \(f(f(x))\) — an exponent counting applications of the machine, as in our Example 3 relay \((f \circ f)\) — then \(f^{-1}\) should name the machine that takes one application back. Compose \(f\) with \(f^{-1}\) and the applications cancel: \(f^{-1}(f(x)) = x\), one step forward, one step back, arriving where you began. The exponent is a composition exponent, not an arithmetic one — and that single distinction, held firmly, prevents the most common error of the entire topic.

All week the two functions in a composition have cooperated: the inner speaks, the outer responds. An inverse pair is that cooperation perfected into mutual undoing: whatever \(f\) does to a number, \(g\) undoes — and, remarkably, whatever \(g\) does, \(f\) undoes right back. Neither function is the master; each returns the other's work exactly. Their composition, in either order, is the do-nothing identity function \(I(x) = x\): the one case promised on Wednesday where \(f \circ g = g \circ f\), and the structural reason could not be more special.

The Verification Ceremony

Functions \(f\) and \(g\) are inverses of each other exactly when both compositions collapse to the identity:

\(f(g(x)) = x \;\text{ for every } x \text{ in the domain of } g, \qquad g(f(x)) = x \;\text{ for every } x \text{ in the domain of } f\)

Then we write \(g = f^{-1}\) and \(f = g^{-1}\). Both orders are required — the ceremony has two parts, and a pair that passes one test can fail the other (the honors stretch below exhibits a famous culprit). Two consequences come free: if \(f(a) = b\) then \(f^{-1}(b) = a\), so every input-output pair swaps; and therefore the domain of \(f\) is the range of \(f^{-1}\), and the range of \(f\) is the domain of \(f^{-1}\) — the two functions trade territories entirely.

Example 1

Verify that \(f(x) = x + 7\) and \(g(x) = x - 7\) are inverses of each other.

Solution:

Run both halves of the ceremony:

\(f(g(x)) = f(x - 7) = (x - 7) + 7 = x\) ✓

\(g(f(x)) = g(x + 7) = (x + 7) - 7 = x\) ✓

Answer: Both compositions are the identity, so \(g = f^{-1}\). Adding seven and subtracting seven undo each other — no surprise, but notice what the ceremony bought: not a feeling of undoing, but a proof, two lines long, that works for every real number at once.

Example 2

Verify that \(f(x) = 3x - 4\) and \(g(x) = \dfrac{x + 4}{3}\) are inverses of each other, and narrate why \(g\) has the form it has.

Solution:

Describe \(f\) as a sequence of duties: multiply by 3, then subtract 4. To undo a sequence you undo each step in reverse order — the socks-and-shoes principle: shoes went on last, so they come off first. So the undoing must add 4 first, then divide by 3 — and that is exactly \(g(x) = \frac{x+4}{3}\). Now the ceremony:

\(f(g(x)) = 3\left(\dfrac{x + 4}{3}\right) - 4 = (x + 4) - 4 = x\) ✓

\(g(f(x)) = \dfrac{(3x - 4) + 4}{3} = \dfrac{3x}{3} = x\) ✓

Answer: Both compositions collapse to the identity, so \(g = f^{-1}\). Watch the algebra of the first composition closely: the \(3\) and the \(\frac{1}{3}\) annihilate first, then the \(+4\) and \(-4\) — the undoing really does happen in reverse order, step by step, right there in the symbols.

Example 3

A student claims \(k(x) = \dfrac{x}{2} - 1\) is the inverse of \(h(x) = 2x + 1\). Put the claim on trial — and if it fails, find and verify the true inverse.

Solution:

The trial is the ceremony:

\(k(h(x)) = \dfrac{2x + 1}{2} - 1 = x + \dfrac{1}{2} - 1 = x - \dfrac{1}{2}\) ✗

Not the identity — the claim is already dead, but run the other order for the autopsy:

\(h(k(x)) = 2\left(\dfrac{x}{2} - 1\right) + 1 = x - 2 + 1 = x - 1\) ✗

Both compositions miss, each by a constant. The diagnosis is a courtesy failure: \(h\) says double, then add 1, so its undoing must subtract 1 first, then halve. The student's \(k\) halves first and subtracts 1 second — the right undoing steps in the wrong order. The true inverse is

\(h^{-1}(x) = \dfrac{x - 1}{2}\)

and it passes both halves of the ceremony:

\(h(h^{-1}(x)) = 2\left(\dfrac{x-1}{2}\right) + 1 = (x - 1) + 1 = x\) ✓ \(\qquad h^{-1}(h(x)) = \dfrac{(2x + 1) - 1}{2} = \dfrac{2x}{2} = x\) ✓

Answer: \(k \neq h^{-1}\); the true inverse is \(h^{-1}(x) = \frac{x-1}{2}\). The moral is the week's convention biting back: composition is order-sensitive, so undoing is order-sensitive too. And note the method: the claim was settled not by opinion or by one lucky test value, but by composition — the ceremony is the court.

Example 4

Verify that \(f(x) = x^3 + 2\) and \(g(x) = \sqrt[3]{x - 2}\) are inverses, then use the pair-swapping consequence: given that \(f(1) = 3\), evaluate \(g(3)\) without computing a cube root.

Solution:

\(f(g(x)) = \left(\sqrt[3]{x - 2}\right)^3 + 2 = (x - 2) + 2 = x\) ✓

\(g(f(x)) = \sqrt[3]{(x^3 + 2) - 2} = \sqrt[3]{x^3} = x\) ✓

(That last step is honest because the index is odd — \(\sqrt[3]{x^3} = x\) for every real \(x\), with no absolute-value ambush. Unit 3's parity lesson, still on duty.)

Now the swap: \(f(1) = 3\) means \(f\) carries \(1 \mapsto 3\), so its inverse must carry \(3 \mapsto 1\).

Answer: \(g = f^{-1}\), and \(g(3) = 1\) — read off, not computed. Every fact you know about \(f\) is a fact about \(f^{-1}\) wearing its coordinates swapped; the two functions share one supply of information, stored in opposite directions.

You Have Already Met an Inverse Pair

In Unit 3 you used two identities so often they became reflexes:

\(\log_{10}\!\left(10^x\right) = x \;\text{ for all } x, \qquad 10^{\log_{10} x} = x \;\text{ for } x > 0\)

Look at them with this week's eyes: they are exactly the verification ceremony — two compositions collapsing to the identity. The exponential \(10^x\) and the logarithm \(\log_{10} x\) are inverse functions, and every equation you solved in Unit 3 by “taking the log of both sides” was an act of composing with an inverse to undo an exponential. You had the practice before the theory; today the theory arrives and finds the seat already warm.

One detail deserves a raised eyebrow: the first identity holds for all \(x\), the second only for \(x > 0\). That small asymmetry is the domain-and-range trade in action — the logarithm's domain is only \((0, \infty)\) because that is the exponential's range. Hold the eyebrow raised until Lesson 4-11, where this pair returns and the loop closes for good.

💻 On Your Calculator: The Signature of Undoing 8 min

An inverse pair has a graphical signature, and Desmos will draw it on demand. At desmos.com/calculator (or below):

  1. Define Example 2's pair: f(x) = 3x - 4 and g(x) = (x + 4)/3.
  2. Graph the two compositions: y = f(g(x)) and y = g(f(x)). Both draw the same graph: the 45° line through the origin — the identity \(y = x\). The identity line is the signature of mutual undoing.
  3. Now graph Example 3's failed pair: define h(x) = 2x + 1, k(x) = x/2 - 1, and plot y = k(h(x)). It draws \(y = x - \frac{1}{2}\): parallel to the identity, half a unit low — a near-miss you can see. Close only counts in horseshoes; the ceremony demands the identity exactly.
  4. One more look, with the fix: add y = (x - 1)/2 (the true \(h^{-1}\)), then turn on a dashed y = x. Look at the graphs of \(h\) and \(h^{-1}\) themselves: mirror images across that dashed line. Every swapped pair \((a, b) \leftrightarrow (b, a)\) reflects across \(y = x\) — next week we make that mirror precise and put it to work.

The calculator confirms; your algebra convinces — and on this week's Focus set, the algebra is the part your teacher reads.

▶  Try it yourself: Verify that \(g(x) = 2x - 2\) is the inverse of \(f(x) = \frac{x}{2} + 1\) — both orders, every step. Work it on paper before you peek.
\(f(g(x)) = \frac{2x - 2}{2} + 1 = (x - 1) + 1 = x\) ✓.   \(g(f(x)) = 2\left(\frac{x}{2} + 1\right) - 2 = (x + 2) - 2 = x\) ✓. Both compositions are the identity, so \(g = f^{-1}\). In words: \(f\) halves then adds 1; \(g\) subtracts 1 then doubles — same steps, undone in reverse order.
▶  Try it yourself: Show that \(f(x) = 6 - x\) is its own inverse, and say what that suggests about its graph.
\(f(f(x)) = 6 - (6 - x) = x\) ✓ — one composition suffices here, since both orders are the same composition. \(f\) is self-inverse: subtracting from 6 undoes subtracting from 6, the way a reflection undoes itself. And since a function and its inverse mirror each other across \(y = x\), a self-inverse function must be its own mirror image — graph \(y = 6 - x\) and \(y = x\) in Desmos and see the perfect symmetry.
⚠️ COMMON MISTAKE
Reading \(f^{-1}(x)\) as \(\dfrac{1}{f(x)}\). The \(-1\) is Herschel's composition exponent — it counts applications of the machine, not factors in a product. The two objects are not merely different; the reciprocal fails the ceremony outright. Take \(f(x) = x + 3\): the reciprocal is \(\frac{1}{x+3}\), and \(f\!\left(\frac{1}{x+3}\right) = \frac{1}{x+3} + 3\), nowhere near \(x\). The true inverse is \(x - 3\). When you need the reciprocal of a function's output, write \(\left[f(x)\right]^{-1}\) or \(\frac{1}{f(x)}\) and leave \(f^{-1}\) to mean what Herschel meant: the undoing.
💡 DID YOU KNOW?
Herschel knew his \(f^{-1}\) notation was a gamble — he admitted the exponent could be misread as a reciprocal, but argued the analogy was too valuable to surrender: composition behaves enough like multiplication that borrowing its exponents lets one symbol system serve two structures. Mathematics kept the bargain, ambiguity and all. Two centuries later the same convention runs through the trigonometry you will meet in Semester 2 — \(\sin^{-1} x\) names an inverse function, not \(\frac{1}{\sin x}\) — so the care you build today is a long-term investment.

Conclusion

This unit's functions have been in relationship all week — combined, chained, cooperating — and today the relationship reached its most courteous form: mutual undoing, each function returning the other's work exactly, their composition in either order the do-nothing identity. You learned the ceremony that certifies the relationship (both compositions, always), the notation that names it (Herschel's composition exponent), the swap that powers it (every pair \((a,b)\) reversed, domain and range trading places), and the pair you had been using all along without the name — the exponential and the logarithm. This is the week's Focus assignment: your teacher will read two verification ceremonies for method, so perform them in full, both orders, verdicts in sentences, nothing waved through. Next week finishes the story: an algebraic procedure for finding \(f^{-1}\) rather than checking a candidate, the mirror across \(y = x\) made precise, the repair for functions that fail to be invertible — you glimpsed the failure in \(\sqrt{x^3}\)'s well-behaved cousin \(\sqrt{x^2} = |x|\) — and, in Lesson 4-11, the exponential-logarithm loop closed for good.

❓ ESSENTIAL QUESTIONS

1. What exactly must be shown before two functions may be called inverses — and why is verifying one composition not half the work, but an unfinished proof?

2. In what sense is the identity function the “do-nothing” of composition, and why is landing on it — exactly, not approximately — the whole test?

3. Why must the undoing steps run in reverse order — and how did Example 3's near-miss candidate fail precisely this principle?

4. The identities \(\log(10^x) = x\) and \(10^{\log x} = x\) served you all through Unit 3. What were they secretly certifying — and why does the second one carry a condition the first does not?
